# Customer Churn & Retention Analysis

## Project Overview
Analyzed the IBM Telco Customer Churn dataset to identify customer churn patterns, understand factors associated with customer attrition, and highlight potential customer retention opportunities.

## Business Objectives
- Measure the overall customer churn rate.
- Identify customer segments with higher churn rates.
- Analyze the relationship between customer tenure, contract type, services, and churn.
- Evaluate monthly charges associated with churned customers.
- Recommend strategies to improve customer retention.

## Tools & Technologies
- **PostgreSQL:** Data cleaning, validation, and SQL analysis.
- **Python:** Exploratory Data Analysis (Pandas, NumPy, Matplotlib, Seaborn).
- **Power BI:** Interactive dashboard and business reporting.

## Dataset
IBM Telco Customer Churn dataset containing 7,043 customer records and 21 columns.

## Project Status
Completed – SQL analysis, Python EDA, and Power BI dashboard.
